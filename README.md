# Mary Had a Little Lamb — B A G 牧童笛練習

獨立靜態 web app，由現有 P3 第二課的 Mary 練習匯出。沒有 Firebase、登入、麥克風、評分或資料收集，不依賴外部 CDN。

## 功能
- 原稿重繪八小節五線譜與音名、換氣記號。
- 樂譜／跟奏畫面切換，4 拍預備，開始／暫停／繼續／重來。
- 慢60／中80／快100 BPM，示範旋律開關。
- B／A／G 指法及單音示範；二分音符和全音符維持原有拍值。
- 全螢幕（依瀏覽器支援）；空白鍵開始／暫停，R重新開始。
- 離開分頁自動暫停，暫停時停止未結束的示範音。

## 開啟
解壓後保持assets資料夾，開啟index.html，或執行 `python3 -m http.server 8750` 後到 http://localhost:8750/ 。iPad使用公開GitHub Pages網址；首次須按播放啟用音訊。橫向使用較清晰。

## 教學版本
沿用教師確認的B A G改編，不另猜曲譜。第三句高音改為B B B；第六小節為B、B、B（一拍、一拍、兩拍）。預備拍有提示聲；關閉示範只關閉旋律。
聲音是瀏覽器合成示範，不是真實牧童笛錄音；音效時序受裝置與瀏覽器限制。
